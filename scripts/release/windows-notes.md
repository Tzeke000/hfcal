## HF Field Antenna — Windows app v{{VERSION}}

Download **HF-Field-Antenna-Setup-x64.exe** below and run it. Windows may warn that the publisher is unknown (the installer is not code-signed): choose **More info → Run anyway**.

**iPhone and Android:** not this page. iPhone uses the website; Android has its own download at **https://github.com/Tzeke000/hfcal/releases/tag/android**.
